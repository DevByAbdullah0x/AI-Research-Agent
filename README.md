# AI Research Agent

An evidence-first web research assistant. It uses Tavily to retrieve current web sources, then asks Google Gemini to create a structured, context-aware answer with inline source links.

## Features

- LLM-powered web research workflow
- Live Tavily search from the Express backend
- Gemini-powered answer generation grounded in retrieved sources
- Markdown research briefs with inline citations
- Source cards with snippets and direct links
- API validation, rate-limit, network, and configuration error handling
- Responsive React/Vite interface

## Architecture

```text
React + Vite UI
       ↓ POST /api/research
Express REST API
       ↓
Tavily Search → retrieved research context
       ↓
Google Gemini → generated answer + citations
       ↓
React UI → answer and source cards
```

## Tech stack

- React 19 and Vite
- Node.js and Express 5
- Tavily Search API
- Google Gemini API (`@google/genai`)
- React Markdown + GFM

## Setup

Prerequisite: Node.js 20 or newer.

1. Clone the repo and enter it:

   ```bash
   git clone https://github.com/YOUR_USERNAME/AI-RESEARCH-AGENT.git
   cd AI-RESEARCH-AGENT
   ```

2. Copy the environment template to `server/.env` and add real API keys. On Windows PowerShell:

   ```powershell
   Copy-Item .env.example server/.env
   ```

   On macOS/Linux:

   ```bash
   cp .env.example server/.env
   ```

3. Install all dependencies:

   ```bash
   npm run install:all
   ```

4. Start frontend and backend together:

   ```bash
   npm run dev
   ```

   Visit `http://localhost:5173`. The API runs on `http://localhost:5000`.

To run separately, use `npm run server` and `npm run client` in two terminals. Create a production frontend build with `npm run build`, then run the API with `npm start`.

## Environment variables

Put these values in `server/.env`; never expose them in the Vite client.

| Variable | Required | Purpose |
| --- | --- | --- |
| `GEMINI_API_KEY` | Yes | Gemini API credential |
| `TAVILY_API_KEY` | Yes | Tavily Search API credential |
| `PORT` | No | API port; defaults to `5000` |
| `GEMINI_MODEL` | No | Defaults to `gemini-3.6-flash` |
| `CLIENT_ORIGIN` | No | Allowed browser origin; defaults to Vite's local URL |

## API

### `GET /api/health`

Returns `200` when the API is running.

```json
{ "success": true, "status": "ok" }
```

### `POST /api/research`

```json
{ "query": "Compare React and Next.js for production web apps." }
```

Successful response:

```json
{
  "success": true,
  "query": "Compare React and Next.js for production web apps.",
  "answer": "A Markdown-formatted, source-cited research brief...",
  "sources": [{ "title": "...", "url": "https://...", "snippet": "...", "score": 0.92 }]
}
```

Error responses contain `success: false`, a human-readable `error`, and a stable `code`. Keys and upstream error details are never returned.

## Implemented Features

1. **Conversation History**:
   - Multi-session chat threads stored in SQLite (`node:sqlite`).
   - Sessions list, rename, delete with cascade.
   - Preserves prior context in the Gemini prompt for continuous follow-up questions.
2. **Streaming Gemini Responses**:
   - Real-time token streaming over Server-Sent Events (`POST /api/research/stream`).
   - Live typing Markdown render with blinking cursor.
   - Interactive stop/cancel button aborting in-flight generation.
3. **Research Depth Controls**:
   - Quick (~3s, 1 query, 3 sources, low cost)
   - Standard (~8s, 1 query, 6 sources, balanced)
   - Deep (~20s, 4 sub-queries generated by Gemini, up to 12 deduplicated sources)
   - Time and estimated cost tradeoff surfaced in the UI.
4. **Source Credibility Filtering**:
   - Multi-signal scoring: HTTPS, academic/government authority, major news/docs reputation, author byline, date recency.
   - Configurable minimum credibility score threshold.
   - Domain type exclusion filters (exclude forums, blogs, wikis).
   - Credibility badges and reasoning displayed on each source card.
5. **PDF & Document Ingestion**:
   - Multi-format file attachment (`.pdf`, `.docx`, `.txt`, `.md`).
   - Text extraction with OCR fallback (`tesseract.js`) for scanned PDFs.
   - Page-aware chunking and BM25 term relevance retrieval.
   - Page-level citations alongside live web sources.
6. **Persistent Research History & Archive**:
   - Independent research run archive decoupled from chat sessions.
   - Search by keyword and filter by date range or topic tag.
   - One-click re-run with fresh web sources or load into chat.
